1->Purpose of map method in javascript 
    The map() method in JavaScript is used to create a new array by applying a specified function to each element in
    an existing array
    
    eg : const numbers = [1, 2, 3, 4, 5];
        const double = numbers.map(rum => num * 2);
        console.log(numbers); [1,2,3,4,5]
        console.log(double); [2,4,6,8,10]

Original array is not altered....

2->What is event bubbling and Event capturing 
    Event capturing : Top down approach 
        -> Event capturing means the event starts from the top-level element and travels down to the element that was clicked.
        -> Events are handled from outermost to innermost 
                        HTML
                        ↓
                        BODY
                        ↓
                        DIV
                        ↓
                        BUTTON ← Clicked


    Event bubbling : Bottom up approach 
        -> Event bubbling : event starts from element that was clickd then moves upward to its parent elements 
        -> Events are handled from innermost to outermost 
        eg : addEventListener() uses event bubbling.

5-> What is Closure in js 
    : A closure is created when an inner function remembers and can access variables from its outer function even after the outer function has finished executing.
    : Closure = Function + its remembered outer variables 
    eg: 
                    function outer() {
                        let count = 0;

                        function inner() {
                            count++;
                            console.log(count);
                        }

                        return inner;
                    }

                    const counter = outer();

                    counter(); // 1
                    counter(); // 2
                    counter(); // 3

7-> Explain concept of Promises in JS 
    : Promises : Handles asynchronous tasks in js 
            -> Pending : waiting   : the operation is still running 
            -> Fulfilled  : Operation was succesfull 
            -> Rejected : Something went wrong 

                 const promise = new Promise((resolve, reject) => {

                            let success = true;

                            if (success) {
                                resolve("Data received successfully");
                            } else {
                                reject("Failed to get data");
                            }

                        });

                -> After creating a Promise, we normally handle its result using:
                    .then() → handles success
                    .catch() → handles failure

                promise
                    .then((result) => {
                        console.log(result);
                    })
                    .catch((error) => {
                        console.log( error);
                    });

9-> What is event deligation 
    ->Event Delegation is a technique where we attach one event listener to a parent element instead of adding separate event listeners to each child element.
    The parent handles events coming from its children using event bubbling.
    : Event Delegation = Put one event listener on the parent and let it handle events from its children. 
    : Advantages : Improves perf,Handles dynamic element
