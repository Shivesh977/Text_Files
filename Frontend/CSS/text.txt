2:General syntax : 

    1:selector{
        property : value ;
    }
                    eg  p{ // select all <p> element
                        color:red;
                        font-size:20px ;
                    }

    2:want to modify class 
        .class_name{
            property:value ;
        }
    3:want to modify id 
        #id{
            property:value;
        }

#########
1:whatever we write inside div tag ; any css property on that div will be applicable to all : div acts as a container 

2:Padding used to move elements inside box/div 
3:margin is used to move box/div

########Display flex : used to arrange html elements in row or a column
->mainly used for layout and alignment
->given to parent element

->eg :          <div class="container">
                <div>Box 1</div>
                <div>Box 2</div>
                <div>Box 3</div>
                </div>

            .container {
                display: flex;
                flex-direction:row/column;
            }

            output   :  ┌───────┐  ┌───────┐  ┌───────┐
                        │ Box 1 │  │ Box 2 │  │ Box 3 │
                        └───────┘  └───────┘  └───────┘
