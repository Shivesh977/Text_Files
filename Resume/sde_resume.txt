######### React.js
->Js library used to build interactive and reusable user interface (UI),especially for web applications
->React helps us with : reusable components,updating ui effeciently , connecting frontend with backend/apis 

        User
        ↓
        Interacts with UI
        ↓
        State changes
        ↓
        React detects change
        ↓
        React updates required UI
        ↓
        Browser displays updated UI

->Components : reusable piece of ui that contains its own structure and logic
->JSX(JavaScript XML) : is a syntax that allows to write html like code inside js 
->State is data maintained by a component that can change over time and cause the UI to update.
->frontend and backend talk to each other\
 via axios (js library)
